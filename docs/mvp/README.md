# MVP 关键画面（2026-10-23，Android 14 模拟器）

| 文件 | 内容 |
|---|---|
| `01_splash_system.png` | 系统启动页：图标 + 底部 App 名称 |
| `03_gmail_confirm_card.png` | 对话页：实时画面卡片 + 邮件确认卡片（收件人、主题、正文是从 Gmail 页面实际读到的）和 发送 / 修改 / 取消 |
| `04_floating_waiting_confirm.png` | 用户离开 App 后的悬浮小窗：等待确认 · 去确认 / 停止 |
| `05_floating_opens_confirm_card.png` | 点小窗「去确认」后打开 App，定位到确认卡片 |
| `06_fullscreen_watch.png` | 全屏观看（真实画面、左上角「×」退出、暂停 / 停止） |
| `07_gmail_sent_result.png` | 点发送后：确认卡片变「已发送」，「已完成」卡片带「已发送」列表截图和依据 |
| `08_calendar_ask.png` | 日历：信息不全时一次问全 |
| `09_calendar_done.png` | 日历：「已完成」卡片，带日程截图和依据 |
| `10_amazon_empty_cart.png` | Amazon：购物车是空的，直接告诉用户（没有对购物车做任何改动） |

Amazon 提交订单页的交接卡片本轮没有重新拍（见 `docs/known-issues.md`「界面与实时画面」一节）；设计稿见 `docs/design/screens/`。
