# 演示脚本

演示三件事：**日历**（追问）、**Gmail**（确认后发送，并展示悬浮小窗）、**Amazon**（交接到主屏，不下单）。总时长约 6～8 分钟。

## 演示前检查清单
- [ ] 模拟器已启动（Pixel 8 / Android 14），**已登录 Google 账号**，日历、Gmail、Amazon Shopping 三个 App 都登录过一次、能正常打开
- [ ] **Shizuku 在运行**并已授权给 PhoneAgent（模拟器重启后要重新启动：`adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh`，或在 Shizuku 里点启动）
- [ ] **悬浮窗权限**已开：`adb shell appops get com.android.phoneagent SYSTEM_ALERT_WINDOW` 显示 allow；没开就 `adb shell appops set com.android.phoneagent SYSTEM_ALERT_WINDOW allow`
- [ ] 安装的是最新的 debug 版（`./gradlew installDebug`）；`local.properties` 里有 `CLAUDE_API_KEY`
- [ ] **Amazon 购物车状态**：想演示「用购物车里现有的」就先放 1 件便宜商品；想演示「搜索加购」就保持购物车为空。**演示中会真实加购，演示后按下面清理**
- [ ] 打开一次 PhoneAgent，确认首页是「想让我帮你做什么？」，对话是空的（关掉 App 进程再开可清空）
- [ ] 网络正常（每步要调用 Claude）
- [ ] **演示后清理**：
  - 日历：删除标题带 `[PA测试…]` / 演示用的事项
  - Gmail：「已发送」里演示的邮件（发给自己的测试邮箱 qijie_jerry@163.com）、草稿箱里可能的残留草稿
  - Amazon：购物车里演示加的商品（可用「把购物车里的 XX 删掉」走确认卡片）；**不要下单**

## 一、日历：说得不全，agent 一次问全（约 1.5 分钟）
**话术**：「我让它帮我记一件事，但故意说得不全。」
1. 输入：`帮我加个日历事项`
2. agent 一次问全：标题、哪天、几点。回答：`标题 演示周会，下周一上午9点`
3. 对话里出现一行复述（「日历：「演示周会」· 10月26日（周一）09:00–10:00（默认 1 小时）」），几秒后出现「已完成」卡片，带日程截图和依据
- 要点：缺信息一次问全；「下周一」直接换成具体日期；时长缺省 1 小时并写明；卡片依据来自界面上真实看到的内容。

## 二、Gmail：确认后才发送 + 悬浮小窗（约 2.5 分钟）
**话术**：「发邮件这种不可撤回的事，它一定先让我确认，而且确认的是页面上真实的内容。」
1. 输入：`给 qijie_jerry@163.com 发邮件，说周五的评审改到下午3点，主题用「[PA测试] 评审改期」`
2. 出现实时画面卡片（Gmail 写邮件页，每秒刷新），随后出现「待发送的邮件」确认卡片：收件人、主题、正文
3. **按 Home 键离开 App**：屏幕边缘出现悬浮小窗「等待确认 · 去确认 / 停止」。话术：「我现在在干别的，它在后台等我。」
4. 点小窗的「去确认」→ 回到 App，自动滚动到确认卡片
5. （可选）点实时画面进入全屏观看，左上角「×」退出
6. 点「发送」→ 卡片变「已发送」，出现「已完成」卡片，依据里是「已发送」列表里看到这封邮件
- 要点：确认内容是从页面读出来的；点发送时系统再核对一次内容，不一致就不放行；任务在后台跑，不抢键盘。
- 想演示修改：点「修改」，说「正文加一句请回复确认」，会出新的确认卡片。**不要演示取消**（已知不稳定）。

## 三、Amazon：到提交订单页，交给我付款（约 2 分钟）
**话术**：「付款这种事 agent 永远不碰，它把我带到最后一步。」
1. 输入：`帮我把购物车带到结算页`（购物车里有 1 件）
2. 复述「Amazon：购物车结算，到提交订单页，付款由你来」；实时画面里走结算流程，遇到 Prime 推广页会点「No thanks」
3. 出现「需要你来完成」卡片：商品小计、订单总价，按钮「去完成」
4. 点「去完成」→ Amazon 出现在真实屏幕上的提交订单页，**停在这里，不点下单**
- 要点：「Place your order」和 Prime 订阅按钮被硬拦截，模型也点不了；多件商品时会先告诉你「结算会包含全部 N 件」。
- 想演示改购物车：`把购物车里的 XX 删掉` → 确认卡片 → 确认后才执行（未确认时点删除会被拦截）。

## 备用说法 / 出问题时
- 澄清追问太多：直接给完整信息（「周三下午3点加日历 演示会」）
- 任务卡住：点「停止」，再说一遍；或 `adb shell am broadcast -a com.android.phoneagent.CMD -n com.android.phoneagent/.CmdReceiver --es cmd taskstop`
- Shizuku 掉了：引导页/设置里会提示未运行；重新启动 Shizuku 后重开 App
- 运行记录（排查用）：`adb pull /sdcard/Android/data/com.android.phoneagent/files/runs/`
