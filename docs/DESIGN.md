# PhoneAgent 视觉与界面设计规范

对应 `docs/PRD.md` v0.5 第 7 章。设计方向：**以对话为中心的深色界面**，参考两张深色聊天界面截图（`docs/design/refs/muse-chat.PNG`、`docs/design/refs/muse-drawer.PNG`）的**配色、层次和版式**。

> **不使用**参考产品的名称、Logo、角色形象或任何其他品牌素材。参考截图只用于提取颜色和布局比例，agent 头像全部是原创矢量图形（第 7 节）。

**所有界面只能使用本文定义的主题值**（颜色、字体层级、间距、圆角、图标），代码里对应 `ui/theme/` 下的令牌，业务界面不得写死数值。

---

## 1. 设计原则

1. **对话是唯一的主界面**：任务、进度、提问、确认、结果都在对话里。没有底部导航栏，没有右上角按钮。
2. **深色优先**：App 默认深色主题；浅色主题按同一套层次关系推导。
3. **层次靠明度，不靠阴影**：页面纯黑 → 卡片深灰 → 输入栏和控件略亮 → 选中态中灰；用细边框分隔。
4. **一种卡片结构**：确认卡片、实时画面卡片、结果卡片共用「图标 + 标题行 → 分割线 → 粗体主内容 → 灰色辅助信息」。
5. **不使用 emoji 作为图标**；图标统一为描边线性图标（第 8 节）。

## 3. 字体层级

字体：系统无衬线字体（Android 为 Roboto + Noto Sans CJK），**不引入自定义字体**。字号单位 sp，行高为 4 的倍数。

| 令牌 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 28sp / 36 | 600 | 引导页标题、空状态里 agent 的名字 |
| `title` | 20sp / 28 | 600 | 卡片标题行、抽屉标题、页面标题 |
| `body` | 16sp / 24 | 400 | 对话正文、输入框文字 |
| `bodyStrong` | 16sp / 24 | 600 | 卡片里的粗体主内容 |
| `label` | 14sp / 20 | 500 | 按钮文字、名字胶囊、选项按钮、抽屉小标题 |
| `caption` | 12sp / 16 | 400 | 灰色辅助信息、步骤序号、时间 |

## 6. 布局规范

尺寸取自参考截图（原图像素 ÷ 3 得到 dp，再取最近的 4 的倍数）。

### 6.1 顶部区域（对话首页）
- 左上角**圆形菜单按钮**：直径 44dp，底 `surfaceControl`，1dp `borderStrong` 边框，中间描边菜单图标（`menu`）；距左边 `s4`。
- 居中：**agent 头像**（直径 64dp），头像下方是**名字胶囊标签**（高 24dp，水平内边距 `s3`，底 `accentContainer`，文字 `label` + `accent`），胶囊与头像底部重叠 `s2`。
- **没有右上角按钮**。
- 顶部区域背景为**半透明**：`background` @ 80%，自上而下渐隐到 0%（对话内容从下面滚过时淡出）。Compose 没有内置的「背景模糊」，所以用半透明渐隐实现；API 31+ 的设备可以再叠一层很弱的模糊（可选）。
- 顶部区域总高 = 状态栏 + 96dp（菜单按钮、头像、胶囊）。

### 6.2 对话流
- 左右页边距 `s4`；消息间距 `s3`。
- **agent 消息**：大圆角（`rCard`）卡片，底 `surface`，内边距 `s4`，文字 `body` + `textOnBubble`；**不在每条消息旁显示头像**；最大宽度 = 屏幕宽 − 2×`s4` − 右侧 `s8`（给用户气泡留出视觉差）。
- **用户消息**：右侧气泡，`rLarge` 圆角，底为 `bubbleTop → bubbleBottom` 纵向渐变，文字 `body` + `onBubble`，内边距水平 `s4`、垂直 `s3`，最大宽度 80%。
- 提问的**选项按钮**放在问题卡片下面，横向换行排列，`rPill`，底 `surfaceControl`，1dp `border` 边框，文字 `label` + `text`；被点中的选项底 `selected` + 文字 `accent`；其余变为 `textTertiary`。

### 6.3 结构化卡片（确认卡片、实时画面卡片、结果卡片）
参考截图里的 Reminder 卡片：

```
┌──────────────────────────────────┐  底 surface，rCard，内边距 s4
│ (图标 24dp)  标题                │  ← 标题行：描边图标 + title（text），行高 28，图标和文字间 s2
├──────────────────────────────────┤  ← 分割线：1dp dividerInCard，上下各 s3
│ 粗体主内容                       │  ← bodyStrong + text
│ 灰色辅助信息                     │  ← caption/body + textSecondary，与主内容间 s1
│ [按钮] [按钮] [按钮]             │  ← 可选按钮行，与上方间 s4
└──────────────────────────────────┘
```
- 实时画面卡片：标题行后是缩略画面（`rSmall` 圆角，按虚拟屏宽高比 9:20 缩放，高度不超过 200dp，居中），下面是主内容（当前步骤）、辅助信息（「步骤 7/30 · 执行中」）、停止按钮。
- 确认卡片：主内容区依次是「收件人」「主题」（`bodyStrong`）、正文全文（`body`，超长时卡片内滚动，最大高度 240dp）；按钮行「发送 / 修改 / 取消」。
- 结果卡片：成功（`success` 对勾图标）、失败（`danger` 警示图标）、交接（`warning` 交接图标）；证据区放截图（`rSmall`）或文字清单（`caption`，等宽感用 4dp 行距）。
- 按钮：高 40dp，`rPill`，水平内边距 `s4`，文字 `label`。主按钮底 `accentContainer`（深色）/ `accent`（浅色）+ 文字 `onBubble`/`background`；次按钮底 `surfaceControl` + 1dp `border` + 文字 `text`；危险按钮文字 `danger`。

### 6.4 输入栏
- 胶囊形（`rPill`），高 48dp，底 `surfaceInput`，1dp `border` 边框；左右外边距 `s4`，底部距屏幕下沿 `s4`（加系统导航栏高度）。
- 左侧「+」图标按钮（24dp 图标，44dp 点击区域，**第一版禁用**，颜色 `iconDisabled`）。
- 中间输入框：文字 `body` + `text`，占位文字 `placeholder`（「给 小云 发消息」，名字取 agent 的名字）。
- 右侧：输入框为空时显示麦克风（**第一版禁用**，`iconDisabled`）；有内容时显示**发送按钮**（直径 36dp 圆形，底 `accentContainer`，图标 `onBubble`）。
- **没有底部导航栏**。

### 6.5 左侧抽屉
参考 muse-drawer：
- 抽屉宽度 = 屏幕宽 × 0.78；背景 `background`；打开时主页面向右推开，露出的主页面圆角 `rCard` 并压暗（`scrim`）。
- 顶部：App 名称「PhoneAgent」（`display` 28sp，`text`），距顶 状态栏 + `s8`。
- 导航项：「对话」「任务记录」，每项高 48dp，左侧描边图标 24dp + 文字 `body`（`text`），项间距 `s1`；**当前项**用 `selected` 药丸（`rPill`）。
- 分割线 `divider`；分区小标题 `label` + `textTertiary`（如「最近任务」），说明文字 `caption` + `textSecondary`。
- 底部：圆形**设置按钮**（直径 44dp，底 `surfaceControlDeep`，1dp `borderStrong` 边框，齿轮图标），距左 `s4`、距底 `s4`。第一版不放搜索和新建按钮。

### 6.6 全屏观看
- 黑色背景 `background`；顶部细条高 32dp（状态 `label` + 步骤序号 `caption`，底 `surface` @ 80%）；画面区域约占屏幕 85%（等比缩放，留黑边，圆角 `rSmall`）；底部按钮栏高 64dp：「暂停」「停止」两个按钮（次按钮样式，停止为危险样式）。
- 点击位置的小圆点：直径 24dp，`accent` 填充 @ 60% + 2dp `accent` 描边，出现后 600ms 内缩放淡出。
- 上滑底部栏展开步骤列表（底部面板，`rCard` 上圆角，`surface`），列表项：序号圆点 + 「看到了什么」（`caption`+`textSecondary`）+「做了什么」（`body`）。

### 6.7 悬浮小窗
- 药丸形（`rPill`），底 `surface` + 1dp `border`，高 40dp（收起）/ 自适应（展开）；左侧状态图标（24dp，状态色），中间一行文字（`label`，最多 24 个字符，超出省略），右侧按钮（`label`）。
- 状态色：执行中 `accent`；等待用户输入完成 `textSecondary`；需要用户回答 `accent`；等待确认 `warning`；需要交接 `warning`；完成 `success`；失败 `danger`；已暂停 `textSecondary`；应用冲突 `warning`；已停止 `textSecondary`。
- 悬浮窗用的是系统叠加层，主题固定使用**深色**令牌（它浮在别的 App 上，不跟随 App 主题）。

## 7. agent 头像（6 个原创矢量形象）

直径 64dp（顶部）、96dp（引导选择、空状态）、32dp（任务记录）。每个头像 = **圆角形体（渐变色）+ 两个圆眼 + 简单嘴形**，用 Compose `Canvas` 绘制，不使用位图。眼睛和嘴为深色 `#101214`；形体渐变色是原创配色（下表），两个主题下都使用同一套。

| 序号 | 名称 | 形体 | 渐变（上 → 下） | 表情 |
|---|---|---|---|---|
| 1 | 圆点 | 正圆 | `#8DB8FF → #3F78E0` | 圆眼，微笑 |
| 2 | 方糕 | 圆角方形（圆角半径 = 边长的 32%） | `#8CF0D0 → #2BAE8A` | 圆眼，小圆嘴 |
| 3 | 水滴 | 水滴形（顶部尖、底部圆） | `#FFC9A8 → #F0804E` | 圆眼，微笑 |
| 4 | 云朵 | 三个圆叠成的云形 | `#CDB8FF → #7A5AE0` | 圆眼，平嘴 |
| 5 | 柠檬 | 横向椭圆，两端微尖 | `#FFEB94 → #E5B72E` | 圆眼，大笑 |
| 6 | 嫩芽 | 圆形，顶部有一片小叶 | `#FFB8D2 → #E0558A` | 圆眼，微笑 |

「开始工作」的小动画：整体向上弹跳 4dp 再回落（240ms，先快后慢），随后眨眼一次（两眼高度缩到 20% 再恢复，160ms）。执行中的呼吸效果：整体缩放 1.00 ↔ 1.03，周期 2400ms。开启系统「移除动画」时只显示静态头像。

## 8. 图标风格

- **描边线性图标**，24dp 画布，1.75dp 描边，圆头圆角（`StrokeCap.Round`、`StrokeJoin.Round`），无填充（选中/强调时才填充）。
- 颜色取自主题令牌（默认 `text`，次要 `textSecondary`，禁用 `iconDisabled`，状态用状态色）。
- 全部用 `ImageVector` 代码绘制，在 `ui/theme/AppIcons.kt`；**不使用 emoji，不引入图标库**。
- 图标清单：`menu`、`plus`、`mic`、`send`（向上箭头）、`stop`（圆角方块）、`pause`、`play`、`check`、`alert`（三角形感叹号）、`handoff`（右上箭头出框）、`mail`、`calendar`、`cart`、`bell`、`settings`（齿轮）、`chat`（气泡）、`records`（列表）、`close`、`chevronRight`、`chevronDown`、`screen`（手机轮廓）、`shield`、`edit`（铅笔）。

## 10. 启动页与 App 图标

### 10.1 启动页
1. 系统 `SplashScreen`（Android 12+，`androidx.core:core-splashscreen`）：**纯黑背景 `#000000`**，居中显示 App 图标。
2. 随后进入 Compose 启动页：纯黑背景，居中 App 图标（96dp），图标下方 App 名称「PhoneAgent」（`title` 20sp，`text`），停留约 1 秒后整体淡出，进入下一页。
3. **首次打开**进入引导页，之后直接进入对话首页（判断依据：本机是否已有 agent 名字）。

### 10.2 App 图标（原创）
- 形象：**一个圆润的对话气泡**，气泡里是一个**向右上的小箭头**（表示「替你在后台办事」）；气泡用 `accent` → `accentContainer` 的浅蓝渐变，箭头为纯黑。
- **自适应图标**：背景层纯黑 `#000000`（适配深色背景和各种遮罩形状）；前景层气泡居中，位于 66% 安全区内。
- 提供**单色层**（`monochrome`），气泡轮廓 + 箭头，供 Android 13+ 主题图标使用。
